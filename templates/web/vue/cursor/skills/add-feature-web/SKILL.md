# Add Feature (Web)

1. Read the architecture, Tailwind, and learned guidance.
2. Define user states, data boundaries, and a testable outcome.
3. Add feature components and typed composables under `src/features/<name>/`.
4. Keep views declarative and side effects outside templates.
5. Cover primary behavior with Vitest and Vue Test Utils.
6. Run `npm test` and `npm run build`.
7. Use the learn skill for non-obvious decisions.

Avoid speculative stores, generic composables, and wrapper components.
