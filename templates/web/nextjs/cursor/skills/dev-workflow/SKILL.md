# Dev Workflow

1. Install dependencies with `npm install`.
2. Run locally with `npm run dev`.
3. Add or update focused Vitest tests alongside changed behavior.
4. Run `npm test`.
5. Run `npm run build` to verify types and the production bundle.

Do not add lockfiles unless the project has chosen one package manager.
