# Dev Workflow

1. Install dependencies with `npm install`; Nuxt prepares generated types.
2. Run locally with `npm run dev`.
3. Add focused Vitest tests with Nuxt Test Utils.
4. Run `npm test`.
5. Run `npm run build` to verify SSR and the production bundle.

Do not add lockfiles unless the project has chosen one package manager.
