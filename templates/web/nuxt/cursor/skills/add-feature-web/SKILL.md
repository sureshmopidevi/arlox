# Add Feature (Web)

1. Read the architecture, Tailwind, and learned guidance.
2. Define the page, SSR/client boundary, user states, and testable outcome.
3. Add conventional pages, components, composables, and server routes only as needed.
4. Keep secrets server-side and use typed Nuxt data primitives.
5. Cover primary behavior with Vitest and Nuxt Test Utils.
6. Run `npm test` and `npm run build`.
7. Use the learn skill for non-obvious decisions.

Avoid speculative stores, plugins, and wrapper composables.
