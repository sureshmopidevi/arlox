# Add Feature (Web)

1. Read the architecture, Tailwind, and learned guidance.
2. Define user states, data boundaries, and a testable outcome.
3. Add feature components and typed state modules under `src/features/<name>/`.
4. Keep markup declarative and side effects explicit.
5. Cover primary behavior with Vitest and Testing Library.
6. Run `npm test` and `npm run build`.
7. Use the learn skill for non-obvious decisions.

Avoid speculative stores, generic state wrappers, and component layers.
